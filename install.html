HOW TO INSTALL

各平台怎么装

装的是网页本身，不是应用商店里的安装包——所以不必审核，也不会有推送打扰。

安卓手机

用 Chrome / Edge 打开本页，点上方「安装到设备」；若没有反应，就去右上角菜单里找「安装应用」或「添加到主屏幕」。

iPhone / iPad

请用 Safari：点底部「分享」→ 向下寻到「添加到主屏幕」→ 添加。此后从主屏幕掀开图标，便是整页的风。

Windows / macOS

Chrome 或 Edge 打开本页，地址栏右侧会亮起安装图标；也可以直接点上方按钮。装好后，在开始菜单或程序坞里搜「风语」。若想要更像软件的形态，就用上面那只桌面版安装程序。

浏览器不给装

部分手机自带浏览器（如微信内置）不肯放手。换 Chrome / Safari，或取一份离线包带在身边。

安装与缓存都留在你自己的设备上；对话、好感度这些痕迹，也只写进本地浏览器，不会被带走。
